# Графический редактор на C# (Paint Application)

Полнофункциональный графический редактор, разработанный на C# с использованием Windows Forms, предоставляющий широкий набор инструментов для рисования и редактирования изображений.

## 🎨 Основные возможности

### Инструменты рисования
- **Карандаш** - свободное рисование с настраиваемой толщиной
- **Ластик** - стирание частей изображения
- **Заливка** - заливка областей выбранным цветом
- **Фигуры**:
  - Прямые линии
  - Прямоугольники
  - Эллипсы

### Работа с выделением
- **Выделение области** - прямоугольное выделение с пунктирной рамкой
- **Перетаскивание выделения** - перемещение выделенных областей
- **Копирование/Вставка** - работа с буфером обмена
- **Вырезание** - удаление выделенной области

### Управление изображением
- **Создание нового холста**
- **Открытие изображений** (поддержка JPEG, BMP)
- **Сохранение работы** (JPEG, BMP форматы)
- **Отмена/Повтор действий** (Undo/Redo)
- **Очистка холста**

### Настройки
- **Палитра цветов** - встроенная палитра и диалог выбора цвета
- **Настройка толщины** - регулировка размера кисти/ластика
- **Пипетка** - выбор цвета с изображения

## 🛠 Технические особенности

### Используемые технологии
- **C#** - основной язык программирования
- **Windows Forms** - для создания пользовательского интерфейса
- **GDI+** - для графических операций
- **Bitmap** - для работы с изображениями
- **Stack** - для реализации Undo/Redo функциональности

### Архитектурные решения
- **Стек состояний** - для отслеживания изменений и реализации Undo/Redo
- **Отложенная отрисовка** - для плавного взаимодействия
- **Обработка событий мыши** - для точного управления инструментами
